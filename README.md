# RYP Web Design

Portfolio gallery for web units — landings, emails, siderails, interstitials, and banners — sized to the media.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS v4
- Brand mark from `public/brand/`

## Develop

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Work data

Categories and placeholder titles live in `src/data/work.ts`. Each category starts with 5 examples; bump to 10 when ready. Drop final art into `public/work/` and wire frames in `UnitFrame` / `WorkSections` when assets land.
